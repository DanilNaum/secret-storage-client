# Secret Storage Client

Клиент для управления секретными записями с чистой архитектурой, разделением локальных и серверных ID, и generic кешированием.


#### Модель Record:
```go
type Record struct {
    ID          string     // Локальный ID (всегда присутствует)
    ServerID    string     // Серверный ID (пустой если не синхронизирован)
    Type        RecordType
    Name        string
    // ... остальные поля
    IsServer    bool       // Указывает, загружена ли запись с сервера
}
```

#### Модель ServerRecord (метаданные):
```go
type ServerRecord struct {
    ID   string     // Серверный ID
    Name string     // Имя записи с сервера
    Type RecordType // Тип записи с сервера
}
```

### Жизненный цикл записи

1. **Создание локальной записи**:
   - Получает локальный ID (`local_1`, `local_2`, ...)
   - `ServerID` остается пустым
   - `IsServer = false`

2. **Синхронизация с сервером** (F4):
   - Запись загружается на сервер
   - Получает серверный ID (`server_local_1`, ...)
   - `ServerID` заполняется в обработчике
   - Создается `ServerRecord` с метаданными

3. **Загрузка с сервера**:
   - Полный контент загружается только при просмотре
   - Кешируется в generic кеше для быстрого доступа
   - Отображается статус кеша

## Отображение в UI

### Детали записи:
```
Name: Email аккаунт
Type: Credentials
Server ID: server_local_3    // Показывается для синхронизированных записей
Username: user@email.com
Password: ********
```

## Горячие клавиши

- `Tab` - переключение между списками/полями
- `F1` - создание записи
- `F2` - **полная синхронизация** (все локальные записи → сервер)
- `F3` - редактирование
- `F4` - **копирование записи** (локальная → сервер или сервер → локальная)
- `F5` - удаление
- `F6` - обновление серверной записи (принудительная загрузка)
- `↑/↓` - навигация
